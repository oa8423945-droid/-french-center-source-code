# French Center — Versions

هذا الريبو يحتفظ بنسختين منفصلتين من مشروع المركز الفرنسي:

- `french-center-1.0`: النسخة التي كانت موجودة في الريبو قبل هذا التحديث.
- `french-center-1.1`: أحدث نسخة من مشروع `source-code -test`، وتشمل تحديثات تسجيل الدخول والصلاحيات وسجل إجراءات المستخدمين.

لكل نسخة ملفاتها الخاصة وتشغَّل من داخل مجلد الإصدار المطلوب.
