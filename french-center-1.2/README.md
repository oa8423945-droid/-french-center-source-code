# المركز الفرنسي — 1.2.0

يحفظ البرنامج بياناته في data/main data 2.xlsx. يحتوي هذا الإصدار على نسخة مطابقة للشيت الحقيقي المرفق، بأسماء المنتجات وكمياتها الأصلية. تظل الأكواد والأسعار غير المكتملة فارغة حتى إدخالها من البرنامج.

من المخزن، اضغط على المنتج لعرض تفاصيله:

- **تعديل تفاصيل المنتج**: عدّل الاسم والتفاصيل وبلد المنشأ والكود والكمية والمورد وسعر الشراء أو البيع من نموذج واحد. تغيّر الكمية يسجل فرقها في حركة «تسوية جرد»، بما فيها تصفير المخزون. تتحدث قيمة المخزون وهامش الربح دون إنشاء بيع أو شراء أو تغيير النقدية أو مديونية المورد أو قيم الزيارات السابقة. تستطيع إدخال سعر واحد وترك الآخر فارغًا لحين استكماله.
- **بحث المخزن**: يفلتر المنتجات أثناء الكتابة بالاسم أو الكود أو التفاصيل أو المورد.
- **تنبيهات المخزون**: تعرض الصفحة الرئيسية أول 10 منتجات ذات كمية 3 أو أقل، مع زر «عرض المزيد» لباقي التنبيهات.

## التشغيل

شغّل «تشغيل النظام.bat» ثم افتح http://localhost:3210. ملف التثبيت يحتوي Node.js ومكتبات التشغيل. عند تشغيل المصدر تحتاج Node.js 22 وتجهيز المكتبات بواسطة npm ci --omit=dev.

ملف المستخدمين هو data/usre.xlsx. عند أول تشغيل لتثبيت جديد، تعرض صفحة الدخول إنشاء حساب المدير؛ اختر اسم المستخدم وكلمة مرور من 12 حرفًا على الأقل وأكّدها. يحتفظ التحديث بحسابات المستخدمين الموجودة. لا يحتوي المثبّت على حسابات أو سجلات تشغيل من جهاز المطور. يفتح «فتح ملف البيانات.bat» قاعدة بيانات المخزن.

## التثبيت والتحديث

ملف الإصدار هو FrenchCenter-Setup-1.2.0.exe. أغلق البرنامج وExcel قبل التثبيت.

في أول تثبيت للإصدار 1.2.0، يحمّل المثبّت الشيت الحقيقي بدل قاعدة البيانات القديمة. إذا كانت قاعدة قديمة موجودة، يحفظها أولًا بجوار الملف باسم main data 2.xlsx.before-1.2.0-<timestamp>.bak. إذا تعذر حفظ النسخة الاحتياطية، يتوقف التثبيت. يحتفظ بملف المستخدمين الموجود.

بعد نجاح التثبيت يسجل العلامة data/real-data-v1.2.0.installed. إعادة تثبيت هذا الإصدار تحتفظ بقاعدة البيانات التي جرى العمل عليها بعد التحديث.

متغير GARAGE_DATA_FILE يسمح باختيار ملف بيانات آخر للتشغيل. عند عدم ضبطه، يختار المشغّل قاعدة البيانات داخل مجلد البرنامج أولًا.
